◈ OVERVIEW

BugTrack is a modern, responsive bug tracking and quality assurance dashboard built with React and TypeScript.

Designed to simplify issue management, it provides a centralised interface for documenting software defects, monitoring their severity, tracking report statuses, and organising QA workflows.

◈ INSTALLATION

Requirements

* Node.js
* npm
* Git

01 — Clone Repository

git clone https://github.com/wickedceo/bugtrack.git

02 — Navigate to Application

cd bugtrack/app

03 — Install Dependencies

npm install

04 — Launch Development Server

npm run dev

GitHub Codespaces

To expose the development server in Codespaces:

npm run dev -- --host 0.0.0.0

◈ DATA HANDLING

BugTrack currently uses in-memory application state for demonstration data.

<details>
<summary><b>Current implementation limitation</b></summary>

Bug reports are not yet connected to a persistent database.

Changes made during a session are reset when the application is refreshed.

Persistent storage is not currently implemented.

</details>
